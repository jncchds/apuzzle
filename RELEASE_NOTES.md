# Release notes

## 0.6.0 - 2026-10-02
- Explain mode (Sun & Moon, Sudoku, Crowns, Hues, Blocks, Plots, Pairs, Campsite, Islands, Lamps, Tetra): the new button next to Hint explains the next step in words, cell by cell, with the reasons behind it; "Do it" plays the step, and you can switch back to playing any time. Entering the mode and each step count as hints
- Hint now plays the next logical step instead of a random cell

## 0.5.1 - 2026-10-02
- Settings: move your progress to another device as a file or as copied text; importing merges, so wins, best times and daily results from both devices are kept
- Solving a daily puzzle as a free game (for example from a shared link) now counts for that day too

## 0.5.0 - 2026-09-30
- Rails: tap a cell to mark it as track or put a "no track" dot on it; track notes count toward the row and column numbers
- Sudoku, Blocks and Plots: pencil marks stay under a placed value and come back when the value is removed
- Hues: pencil marks for candidate colors
- Release notes in Settings
- About & licenses shows the app version, copyright and credits

## 0.4.1 - 2026-09-28
- Web: an "Install app" button in Settings and on the home screen (with Add to Home Screen steps on iOS)

## 0.4.0 - 2026-09-27
- Strategy lessons for every game: 50 advanced lessons, one technique each, in a new Strategies tab of the tutorials
- Tutorials reviewed: clearer boards in the dark theme and texts that don't depend on theme colors
- README: all games with screenshots, links to the web version and downloads

## 0.3.2 - 2026-09-27
- New puzzles: Rails (Train Tracks), Arrows (Yajilin), Blocks (Suguru), Pairs (Norinori), Plots (Fillomino) and Links (Numberlink), each with a tutorial
- The new puzzles join the daily challenges from 2026-09-28

## 0.3.1 - 2026-09-25
- Interactive tutorials for every game: tiny boards, one rule at a time, with "Show me"
- The first game of a type offers its tutorial; all tutorials are one tap away from the home screen and the rules dialog

## 0.3.0 - 2026-09-25
- Daily challenges: three games a day at every difficulty, a calendar with your progress, and today's progress on the home screen

## 0.2.1 - 2026-09-25
- New puzzle: 2048, with a target tile or free play
- New app icon and splash screen
- LITS renamed to Tetra
- MIT license

## 0.2.0 - 2026-09-25
- Web: the address follows the screen, so the browser's back and forward buttons work
- The home screen shows the app version, which links to GitHub
- Link previews for shared puzzles

## 0.1.5 - 2026-09-25
- New puzzles: Campsite (Tents), Islands (Nurikabe), Lamps (Light Up), Fence (Slitherlink), Pearls (Masyu) and Mines
- Mines never needs guessing, and digging a mine flags it instead of ending the game

## 0.1.4 - 2026-09-25
- New puzzle: Labyrinth, a maze from the top-left to the bottom-right corner

## 0.1.3 - 2026-09-25
- Ukrainian, Polish and German translations, following the system language, with a language setting

## 0.1.2 - 2026-09-25
- New puzzle: Pop, a bubble breaker with four modes and clear, target or free-play goals
- New-game options for games that have them, kept in share codes, with stats per variant
- Android: a Settings shortcut to make share links open in the app

## 0.1.1 - 2026-09-25
- Share codes and links: every puzzle has a code that recreates it; links open the web version or the Android app, and codes can be pasted on the home screen

## 0.1.0 - 2026-09-25
- First release: Sun & Moon, Sudoku, Crowns, Hues, Mosaic, Blend, Pipes, Shikaku, Trail, Atoms and LITS, generated on the device, each with exactly one solution
- Undo and redo, timer, hints, saving and resuming, and stats
- Sudoku: same-value and row, column and box highlights; an optional setting to remove pencil marks automatically
- Hues: clue numbers count down as matching cells are painted
- Builds for Android, Windows, web and iOS
